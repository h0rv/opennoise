Source observations and model suggestions

This atlas groups exact named musical values retained in open metadata. A source tag or genre observation is an observation; a descriptor on a credited release supplies release context. An inferred suggestion is a separate model proposal. These roles can overlap across artists and must not be added into a single source membership count.

Labels and aliases are source-derived candidates. Dictionary matches do not validate a style taxonomy or add native genre memberships. Geometry is fitted offline from source co-occurrences, excluding inferred proposals; styles with indistinguishable or insufficient evidence remain unplaced and available in List.

Artist maps contain a bounded sample of source artists. Positions infer overlap in their source musical metadata, not sonic distance. The sample List includes unplaced profiles; complete paginated source cohorts remain in the evidence panel. Artist search covers the complete source catalog.

Artist rows are alphabetic by source display name and exact ID, not ranked by musical importance. Proposal scores are uncalibrated association strengths, not probabilities. This local preview contains metadata only.

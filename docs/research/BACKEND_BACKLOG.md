# Backend execution backlog

Backend work proceeds with retained, approved inputs when one source is
unavailable. This backlog separates executable pipeline work from dependencies
that need new source access or independent judgments. No paid services, new
credentials, experimental deployment or acquisition retries are part of these
tasks. Source-specific denials remain in force until relevant access evidence
changes.

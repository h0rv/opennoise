## Current public and research outputs

The sealed public database contains 1,331 artists, 746 genres, 4,948 direct artist genre claims, 34,348 public genre-neighbor rows, 26,525 profile membership rows, and 3,344 representative rows. The direct claims are all Wikidata P136 observations. The public genre-to-artist, artist-to-genre, and shared-direct-genre endpoints therefore have a clear factual source but sparse and uneven coverage.

The local peer research index is `.cache/musicbrainz-full-seed-targets/pipeline/peer-similarity-local-research.sqlite`. It contains 6,291 retained seed rows and 28,508 canonical MusicBrainz peer edges. The community layout places 1,580 seeds and explicitly leaves 4,711 unplaced. It is local research only and is not a public similarity service.

## Priority work

The first offline co-listen ranking evaluation is recorded in [ListenBrainz offline co-listen experiment](LISTENBRAINZ_OFFLINE_CO_LISTEN_EXPERIMENT.md). It uses four earlier daily windows for training and three later windows for evaluation. It excludes pairs already seen in training and reports only aggregate metrics. A pair that repeats across days has a count of supporting windows. The per-day distinct-user counts must never be summed and described as global unique listeners. Do not add a UI, API, or raw-pair lookup while the source policy denies display and local search.

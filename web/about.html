Rebuilding a
map of music.

OpenNoise is an open-source genre atlas inspired by Every Noise at Once. Listening patterns connect artists. Audio features help place them. Genre labels give those patterns names.

This is a supervised reproduction, not an independent rediscovery. We use Every Noise names and memberships to train 4,344 shipped genres. Today’s positions are computed, not copied, but the listening/audio input was originally selected using Every Noise coordinate scores. Earlier builds fitted its coordinates directly.

01

The problem

Every Noise at Once, created by Glenn McDonald, maps thousands of music genres using Spotify-derived listening and audio information. Its spatial arrangement makes an unusually detailed musical vocabulary browsable.

Reproducing that experience is harder than drawing the map. Genres overlap, regional scenes have sparse data, and many micro-genre names are missing from general music databases. Open listening data does not cover the same people or artists as Spotify.

Similarity is not a label

Two artists can share listeners without sharing a genre. A scene can span several sounds.

A cluster is not a genre

Finding a group is easier than giving it a useful name. Broad tags miss local distinctions.

A map is a compression

Two dimensions cannot preserve every relationship. Nearby labels are not a ranked recommendation.

02

From listens
to a map

The Map combines listening similarity with audio descriptors; its orientation follows rhythmic and acoustic/electronic features. Islands uses a separate similarity layout. Related genres are ranked from the saved listening-and-audio vectors, not from distance on screen.

Micro-genres use visible Every Noise names and memberships as evidence alongside places and styles. This helps represent terms absent from other sources, but it means these names are not all independently discovered. Some exported child clusters are qualified by an artist’s name; they are hidden from map labels and genre search.

The data

Inputs and what we use them for
Source Role Terms / limits
ListenBrainz Per-user artist counts build the listening graph and listening vectors. CC0. The audience is not representative of all listeners.
MusicBrainz Artist IDs, names, external links, and areas connect the datasets. Core data: CC0. User tags have different terms and are not used for release naming.
Discogs Release styles name clusters and rerank similar artists. CC0 dump fields. Coverage depends on available releases and artist links.
Wikidata Genre labels, aliases, artist genres, and geography enrich names. Held-back artist genres also supply a test. CC0. Some genre concepts link to Every Noise, so this is not wholly independent.
AcousticBrainz Recording-level audio descriptors are averaged by artist for layout features. CC0. Incomplete coverage; missing audio-axis values use listening neighbours.
Every Noise at Once Genre names and artist memberships supervise the model. Archived coordinates score maps and previously guided fitting and model selection. Third-party archived snapshots; no open-data license established. Not CC0.

Deezer supplies on-demand listening previews in the interface, not the shipped genre graph. Deezer graph experiments, extra Last.fm listening datasets, and the noncommercial Discogs-EffNet audio model were investigated separately; they are not inputs to this release’s layout.

Exact snapshots, hashes, and recorded terms: source manifest. Open-source code does not make every input or derived dataset openly licensed.

Can the graph recover genres it was not shown?

For evaluation, we hide one fifth of eligible Every Noise genres, including all their training memberships. The listening-graph model finds a matching cluster for 210 of 868 hidden genres. “Matching” means the shared artists are at least 20% of the combined set; it does not mean an exact membership or name match.

These are graph-recovery baselines, not scores for every feature of the final website. Most hidden Every Noise genres are not recovered by this test. The same hidden-name benchmark was used to select a naming variant, so it is not an untouched final test for naming. The production export refits on all eligible labels, including evaluation genres; the shipped catalog is not the held-out test.

05

What we borrow.
What we build.

“We did not copy anything” would be false. Every Noise supplies part of the taxonomy and training memberships. The useful question is which outputs are computed from our model, which inputs come from the reference, and what the tests actually establish.

Borrowed as supervision

Genre names, artist–genre examples, and visible name fragments for micro-genres. This trains 4,344 shipped genres, not only names missing elsewhere. The audit found no rule limiting Every Noise seeds to otherwise unavailable genres.

Computed here

Listening similarities, propagated membership scores, discovered communities, enriched names, and two-dimensional positions.

Coordinates: a mixed history

Not targets in the current fit, but they guided the inherited input choice. Earlier builds fitted Every Noise positions directly. “Coordinates never influenced this release” would be false.

How the map changed

  1. Earlier buildsDirect coordinate fitting

    A model predicted Every Noise x/y. The archived v1 also had a local bootstrap that displayed reference positions and colors; that is not the current release.

  2. Input selectionCoordinate-based comparison

    Listening plus audio became the default after comparison with Every Noise’s map. That choice remains in the live model.

  3. ReplacementAudio-oriented positions

    The coordinate-trained model was removed. This did not independently reselect the listening/audio input.

  4. Current releaseComputed geometry

    UMAP fits listening-and-audio vectors. Audio features orient the Map. Every Noise labels and the earlier selection still influence the result.

Checks you can inspect

  • Hidden genre labels. The evaluation split removes entire genres from training, not just random artist links. It tests recovery of their artist groups, not independence from all Every Noise concepts.
  • Export scores. The export matches supervised rows to cached model predictions, not raw lists pasted into the catalog. Its “zero unexplained rows” field is hardcoded after that comparison; it does not measure overlap with Every Noise memberships or establish independence.
  • Released geometry. Across 4,414 matching top-level names, only 2.35% of the Map’s ten nearest neighbours match the final Every Noise map (Islands: 2.70%). The artifact comparison supports new geometry, not zero data dependence.
  • External labels. Some Wikidata artist genres are sealed off from training. A separate slice excludes genres carrying an Every Noise ID, but overlapping sources and concepts still limit independence claims.

The independent audit compared the live payload with the release archive, checked its hashes, and traced the producer code and build history. It found no current path that copies Every Noise positions, colors, or site assets. It did find the inherited coordinate-based selection and extensive membership supervision described above.

This supports a model-built atlas with disclosed dependence—not a clean-room reproduction or proof that we never copied. A stronger claim needs a new feature-selection run without coordinate files, comparisons with no Every Noise seeds, a fresh untouched test, and exact producer configs published with the release. The audit did not refit the full model, determine rights to derived data, or establish what every historical deployment served.
